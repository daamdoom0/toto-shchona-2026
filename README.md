# טוטו מונדיאל 2026 🏆

טוטו שכונתי למונדיאל 2026 - אפליקציית Next.js + Supabase. עיצוב בסגנון טוטו ישראלי קלאסי עם נגיעות אווירה של ארה״ב.

> **מי שזה?** אפליקציה לקבוצת חברים (10-50 איש) שירצו להמר 1/X/2 על כל 72 משחקי הבתים, כל סבבי הנוקאאוט, וגם על אלוף הטורניר ומלך השערים.

- ✅ הרשמה עצמאית עם מייל וסיסמה
- ✅ הימור 1/X/2 על כל 104 המשחקים של מונדיאל 2026 (משחקים מוטמעים מראש)
- ✅ הימורים מיוחדים: אלוף ומלך השערים

## 🚀 הוראות התקנה מלאות

### שלב 1: יצירת פרויקט ב-Supabase

1. היכנס ל-[supabase.com](https://supabase.com) → התחבר / צור חשבון
2. לחץ "**New Project**"
3. שם: `toto-mondial-2026` (או מה שאתה רוצה)
4. סיסמת ה-DB: בחר משהו חזק ושמור אצלך
5. אזור: `Frankfurt` או הקרוב ביותר אליך
6. תוכנית: **Free** (מספיק לקבוצה של 50 איש)
7. לחץ "Create new project" וחכה 2-3 דקות

### שלב 2: יצירת הסכמה והזנת נתונים ראשוניים

ב-Supabase של הפרויקט החדש שלך:

1. לך ל-**SQL Editor** (סמל מסד הנתונים בצד שמאל)
2. הרץ קובץ אחרי קובץ **בסדר הזה** - תיצור Query חדש לכל קובץ, תדביק, ותריץ:
   - `supabase/01_schema.sql` - יוצר את כל הטבלאות והמדיניות
   - `supabase/02_seed_settings.sql` - מגדיר את שעת נעילת הטורניר
   - `supabase/03_seed_matches.sql` - מטעין את כל 104 המשחקים

3. בסיום, רוץ זה בשביל לוודא שהכל תקין:
   ```sql
   select stage, count(*) from public.matches group by stage order by stage;
   ```
   אמור להחזיר: `final 1, group 72, qf 4, r16 8, r32 16, sf 2, third 1` (סה״כ 104)

### שלב 3: שליפת מפתחות API מ-Supabase

ב-Supabase → **Project Settings** (סמל גלגל שיניים) → **API**:

- העתק את **Project URL** (נראה כמו `https://xxx.supabase.co`)
- העתק את **anon public** (מפתח ארוך שמתחיל ב-`eyJ...`)

### שלב 4: הרצה מקומית (לבדיקה)

```bash
# בתיקיית הפרויקט
npm install

# צור קובץ .env.local על בסיס .env.example
cp .env.example .env.local
```

ערוך את `.env.local` ושים שם את הערכים מ-Supabase:

```bash
NEXT_PUBLIC_SUPABASE_URL=https://YOUR-PROJECT-ID.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
ADMIN_EMAIL=your-email@example.com
```

הרץ את האפליקציה:
```bash
npm run dev
```

פתח ב-http://localhost:3000 → לחץ "להרשמה" → רשום את עצמך **ראשון** (כי המשתמש הראשון נהיה אדמין אוטומטית).

### שלב 5: דיפלוי לכל העולם דרך Vercel

1. דחוף את הקוד ל-GitHub (חינמי):
   ```bash
   git init
   git add .
   git commit -m "טוטו מונדיאל 2026 - גרסה ראשונה"
   gh repo create toto-mondial-2026 --private --source=. --push
   # או דרך אתר GitHub - צור repo חדש ועקוב אחרי ההוראות
   ```

2. היכנס ל-[vercel.com](https://vercel.com) → התחבר עם GitHub
3. **Add New** → **Project** → בחר את הפרויקט `toto-mondial-2026`
4. ב-Environment Variables, הוסף:
   - `NEXT_PUBLIC_SUPABASE_URL` = הערך מ-Supabase
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = הערך מ-Supabase
   - `ADMIN_EMAIL` = המייל שלך
5. לחץ **Deploy**. אחרי דקה-שתיים, תקבל URL ציבורי.

## 👤 כללי משחק

### שלב הבתים
- מהמרים 1/X/2 על **כל 72 המשחקים** מראש
- מהמרים גם על **אלוף הטורניר** ועל **מלך השערים**
- **הכל ננעל בשריקה הראשונה של המשחק הראשון** (Mexico vs South Africa, ה-11/6/2026 בשעה 22:00 שעון ישראל)
- אחרי הנעילה - אפשר רק לראות את ההימורים של עצמך ושל אחרים, אבל לא לשנות

### שלב הנוקאאוט
- מתחילים להמר על סבב נוקאאוט **רק כשהזוגות מוגדרים** (האדמין מעדכן את הנבחרות בכל שלב)
- כל סבב ננעל ברגע שריקת המשחק הראשון של אותו סבב
- מהמרים 1/X/2 (לפי 90 דק׳ בלבד, לא תוספת זמן)

### ניקוד
| שלב | נקודות לניחוש 1X2 נכון |
|------|------------------------|
| שלב הבתים | 3 |
| שמינית גמר (R32) | 4 |
| שמינית סופית (R16) | 6 |
| רבע גמר | 10 |
| חצי גמר | 15 |

האדמין יכול לשנות את הניקוד דרך SQL Editor (`update tournament_settings set pts_group = 5;` למשל).

## 🛡️ אבטחה - איך זה עובד?

ה-Backend אוכף ברמת מסד הנתונים (Postgres Row Level Security) את הכללים הבאים:

- **משתמש רואה את ההימורים של עצמו תמיד.**
- **את ההימורים של אחרים** - רק אחרי שעת הנעילה הרלוונטית.
- **שינוי הימור** מותר רק לפני שעת הנעילה.
- **תוצאות + שעות נעילה** ניתן לעדכן רק אם המשתמש הוא אדמין.

אי אפשר ״לרמות״ - גם אם משתמש פותח את ה-Dev Tools של הדפדפן, הוא לא יוכל לראות הימורים של אחרים לפני הנעילה כי ה-RLS חוסם את זה ברמת ה-DB.

## 🛠️ פעולות שכיחות של אדמין

### עדכון תוצאת משחק
1. לך ל-`/admin/results`
2. בחר את השלב (בתים, R32, וכו׳)
3. עבור כל משחק שהסתיים: לחץ 1, X, או 2 + אופציונלית הזן שערים → "שמור"
4. הניקוד יתעדכן אוטומטית בלוח התוצאות

### הגדרת נבחרות בסבב נוקאאוט
1. אחרי שהסתיים שלב הבתים והודיעו על הצמדים (FIFA + הפיפ הרשמי)
2. לך ל-`/admin/results` → R32
3. עבור כל משחק נוקאאוט: בחר את הנבחרת הבית והנבחרת החוץ → "הגדר נבחרות"
4. ההימורים נפתחים אוטומטית למשתמשים עד שעת המשחק

### הזנת אלוף ומלך שערים
1. בסיום הגמר, לך ל-`/admin/results` → הגמר
2. למטה תראה טופס "תוצאות הימורים מיוחדים"
3. בחר את האלוף, רשום את מלך השערים → "שמור"

### הוספת אדמין נוסף
1. לך ל-`/admin/users`
2. מצא את המשתמש → "הפוך לאדמין"

## 🐛 בעיות נפוצות

### "שגיאה בטעינת נתונים"
- ודא ש-3 קבצי ה-SQL רצו בלי שגיאות
- ודא שמשתני הסביבה ב-Vercel/`.env.local` נכונים

### "אני לא יכול להמר - המערכת אומרת שזה נעול"
- ייתכן ששעת המשחק חלפה. בדוק ש-Supabase מציג שעה נכונה.
- אם זה משחק נוקאאוט - האדמין צריך לעדכן את הנבחרות קודם.

### "המייל לא מאשר חשבון"
- כברירת מחדל, Supabase מבקש אישור מייל. לקבוצה קטנה זה לעיתים מסבך - אפשר לבטל ב-Supabase → Authentication → Providers → Email → להוריד את "Confirm email"

### "אני רוצה לשנות את שעת הנעילה"
- ב-Supabase SQL Editor:
  ```sql
  update public.tournament_settings 
  set group_lock_at = '2026-06-11T19:00:00Z' 
  where id = 1;
  ```
